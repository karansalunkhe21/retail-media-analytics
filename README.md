# Retail Media Analytics Data Product

## Overview
A end-to-end data product simulating a retail media analytics 
framework — built to demonstrate data product analysis, SQL 
modeling, governance, and BI dashboard skills.

## Tools Used
- DuckDB (SQL querying)
- Looker Studio (Dashboard)
- Python (data loading)
- GitHub (version control)

## Project Structure
- `sql/` — All SQL scripts organized by phase
- `docs/` — Gap analysis, data dictionary, PRD, backlog
- `dashboard/` — Looker Studio link and screenshots
- `exports/` — Clean CSVs for dashboard use
