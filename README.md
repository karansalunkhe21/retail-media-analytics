# Retail Media Analytics Data Product

## Overview
An end-to-end data product simulating a retail media analytics 
framework — built to demonstrate data product analysis, SQL 
modeling, governance, and BI dashboard skills.

## Tools Used
- DuckDB (SQL querying)
- Looker Studio (Dashboard)
- GitHub (Version control)

## Project Structure
- `sql/01_audit` — Data quality audit queries
- `sql/02_modeling` — Clean data models and views
- `sql/03_analysis` — Business analysis queries
- `docs/` — PRD, data dictionary, gap analysis, backlog
- `exports/` — Clean CSVs for dashboard

## Key Findings
- Smartphones drive 75%+ of total revenue
- Apple generates 2x Samsung revenue despite fewer views
- 32% of category data is missing — flagged for engineering
- 11 data gaps identified, documented, and prioritized
